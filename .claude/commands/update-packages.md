Update all dependencies and bump the version of the package specified in $ARGUMENTS (e.g. Dictionary, Dropdown, CheckBoxList, RadioButtonList).

## Step 1 — Check latest npm package versions

Run `npm view <package> version` for each of these and compare against the current versions in `package.json` (root) and `AndrewK.Umbraco.Extensions.Tests.Client/package.json`:

Root `package.json`:
- `npm view @umbraco-cms/backoffice version`
- `npm view lit version`
- `npm view prettier version`
- `npm view typescript version`
- `npm view vite version`

Tests client `AndrewK.Umbraco.Extensions.Tests.Client/package.json`:
- `npm view @playwright/test version`
- `npm view playwright version`
- `npm view @types/chai version`
- `npm view @web/test-runner version`
- `npm view @web/test-runner-playwright version`
- `npm view @web/dev-server-esbuild version`
- `npm view @open-wc/testing version`
- `npm view @web/test-runner-junit-reporter version`

## Step 2 — Check latest dotnet package versions

Run `dotnet list package --outdated` to find outdated NuGet packages. Update versions in `Directory.Packages.props` for any that have newer releases. Do NOT change `AndrewK.Umbraco.Dictionary` here — that gets updated after publishing.

## Step 3 — Update npm package.json files

Update the version range specifiers in:
- `/package.json` (root) — shared deps: `lit`, `@umbraco-cms/backoffice`, `prettier`, `typescript`, `vite`
- `AndrewK.Umbraco.Extensions.Tests.Client/package.json` — test deps

Then run from repo root:
```
npm install
npm audit fix
```

## Step 4 — Bump the package version

The package to update is: **$ARGUMENTS**

Determine the next patch version (e.g. `17.0.2` → `17.0.3`) and update it in these two files:

1. `AndrewK.Umbraco.Extensions.$ARGUMENTS/AndrewK.Umbraco.Extensions.$ARGUMENTS.csproj`
   - `<PackageVersion>`
   - `<PackageReleaseNotes>` — summarise what changed (dependency versions updated)

2. `AndrewK.Umbraco.Extensions.$ARGUMENTS/client/public/umbraco-package.json`
   - `"version"`

The `wwwroot/umbraco-package.json` is generated by the build — do not edit it manually.

## Step 5 — Build the Lit client

```
cd AndrewK.Umbraco.Extensions.$ARGUMENTS/client && npm run build
```

Verify the build succeeds and `wwwroot/` is updated.

## Notes

- After publishing the new Dictionary NuGet package, update `AndrewK.Umbraco.Dictionary` version in `Directory.Packages.props`, then repeat steps 4–5 for the remaining packages (Dropdown, CheckBoxList, RadioButtonList) since they depend on Dictionary.
- Each package has its own independent version number — do not bump packages that aren't being released.
